## Ajouter une nouvelle démo

1. Créer un dépôt **public** pour la démo (ex. `client-maquette`) et y mettre le site dans un dossier `docs/`.
2. Dans le dépôt : **Settings → Pages → Branch : main, dossier /docs → Save**. La démo sera à `https://dadalo29.github.io/client-maquette/`.
3. Dans ce dépôt-ci, ajouter une capture `images/client.jpg` (1200 × 750) et copier le bloc `<a class="demo">…</a>` de `index.html` en changeant le lien, l'image et les textes.
4. Ajouter une ligne au tableau ci-dessus.

Toutes les pages sont en `noindex` : elles ne sont pas référencées sur Google.
